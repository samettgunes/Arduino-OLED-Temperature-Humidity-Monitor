Arduino OLED Temperature & Humidity Monitor

About the Project

This project is a temperature and humidity monitoring system developed using an Arduino UNO, DHT11 sensor, and OLED display.

The DHT11 sensor measures the ambient temperature and humidity. The measured values are displayed in real time on the OLED screen.

Components Used:
Arduino UNO
DHT11 Temperature and Humidity Sensor
0.96" OLED Display (I2C)
Breadboard
Jumper Wires
Features
Real-time temperature measurement
Real-time humidity measurement
OLED display for data visualization
